# Portfolio — Ruth Musasa | Web Creator

Portfolio personnel de création de sites web : direction artistique minimaliste / brutaliste, titre central **PORTFOLIO**, accent rouge vertical, menu bas en cartes pendule.

## Fonctionnalités

- **Navigation interactive :** cartes en éventail qui basculent au mouvement de la souris (effet pendule).
- **Indicateur ME :** point d’ancrage en bas de l’écran.
- **Pages :** Accueil, Services, Projets, Contact.
- **Responsive :** adapté mobile et bureau.

## Stack

**Vite + React + Tailwind CSS v4 + GSAP**

- React pour le hero, les cartes et les pages.
- GSAP pour le balancier, l’inertie et le suivi souris.

## Démarrage

```bash
npm install
npm run dev
```

Le site s’ouvre sur `http://localhost:5173/`.
